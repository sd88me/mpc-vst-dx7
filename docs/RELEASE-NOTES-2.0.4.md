# Dexed (DX7) 2.0.4

**New: name a favourite.** +FAV on the CARTS page now opens an on-screen keyboard with the voice's name. Edit it (up to 10 characters, as on a DX7; SHIFT, DEL, SPACE), then SAVE stores the voice with your edits under that name, or CANCEL stores nothing. The name shows in MPC's PRESET list as before.

Nothing else changed: same parameters and ID, and the new keyboard keys are added after the existing parameters, so saved projects load as before. Install over 2.0.x or 1.x as before. Zips: `-mpc-armv7` (Force, Live, One, X, Key), `-mpc-aarch64` (Gen 2 units), and `-mpc-sdk` (one folder for MPC OS 3.10.1's `VST2 Plugins`).

**Checked:** on an MPC Live III with a beta build of this code (typing, SAVE, CANCEL, the name in the PRESET list). A project saved with 2.0.3 was not reloaded on a device.
