# Dexed (DX7) 2.0.5

**Favourites survive an upgrade.** The installer now lists `favourites.dat` as your data, so installing a new version (with `install.sh` or the OpenMPC Plugin Manager) keeps your favourites. Before, only your carts were kept and an upgrade deleted the favourites.

**README:** install steps per format (the `VST2 Plugins` folder or `install.sh`, by hand or with the Plugin Manager), and a new section on backing up and restoring your favourites and carts.

Nothing else changed: same sound, parameters and ID, so saved projects load as before. Zips: `-mpc-armv7` (Force, Live, One, X, Key), `-mpc-aarch64` (Gen 2 units), and `-mpc-sdk` (one folder for MPC OS 3.10.1's `VST2 Plugins`).
