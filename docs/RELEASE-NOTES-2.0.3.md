# Dexed (DX7) 2.0.3

**Fixed: the cart (bank) control on the data wheel or a Q-Link.**
- Turning back now steps back. Before, the first few clicks after a fast turn could go the wrong way.
- Fast clicks are no longer merged into one step, or lost at the bottom of the list. Very fast turns down can still drop the odd click.

Nothing else changed: same skin, parameters and ID. Install over 2.0.x or 1.x as before. Zips: `-mpc-armv7` (Force, Live, One, X, Key), `-mpc-aarch64` (Gen 2 units), and `-mpc-sdk` (one folder for MPC OS 3.10.1's `VST2 Plugins`).

**Checked:** on an MPC Live III with a beta build of this code.
